# 🎬 Mmmovierate Bot

Telegram бот для отслеживания фильмов, сериалов и аниме.

## Функции
- 🔍 Поиск через TMDB (фильмы, сериалы, аниме)
- ❤️ Список желаний
- ✅ Список просмотренного с оценками
- 📤 Советовать фильмы друзьям
- 📬 Входящие советы от друзей
- 👤 Профиль со статистикой

## Деплой на Railway

1. Создай новый проект на Railway
2. Подключи GitHub репозиторий
3. Добавь переменные окружения:
   - `BOT_TOKEN` — токен от @BotFather
   - `TMDB_API_KEY` — ключ от themoviedb.org
4. Railway автоматически запустит бота через Procfile
